# 오늘의 부산 앞바다

국립해양조사원 해양관측부이와 기상청 초단기실황 데이터를 바탕으로 부산 9개 해역, 12개 어종의 환경 적합도를 계산해 보여 주는 프로토타입입니다. Next.js(App Router), TypeScript, React, Tailwind CSS, Leaflet/OpenStreetMap, Recharts, Lucide React로 구성했습니다.

> 실시간 관측 데이터는 공식 API에서 가져오지만, 어종 예측은 규칙 기반 참고용 계산입니다. 실제 어획 확률을 의미하지 않습니다.

## 주요 화면과 기능

- 첫 화면: 선택 해역의 수온·바람·파고·조류·날씨, 상위 3개 어종, 환경 차트
- 지도: 부산 9개 해역 마커, 상태 범례, 해역별 하단 상세 시트
- 해역 상세: 12개 전체 어종 순위, 정렬과 상태 필터
- 어종 상세: 항목별 적합도 차트, 현재 환경과 선호 환경, 판단 이유와 누락 데이터
- 데이터 누락·오래된 관측·잘못된 주소에 대한 안내 상태

## 설치와 실행

```bash
npm install
npm run dev
```

루트에 `.env.local`을 만들고 공공데이터포털 일반 인증키(Decoding)를 설정합니다.

```env
KHOA_API_KEY=발급받은_국립해양조사원_API_키
KMA_API_KEY=발급받은_기상청_API_키
```

키가 없거나 외부 API가 응답하지 않으면 앱은 중단되지 않고 `src/data/marine-observations.ts`의 예시 데이터로 전환됩니다. 운영 환경의 키는 소스에 넣지 말고 호스팅 서비스의 비밀 환경변수로 등록해야 합니다.

검증 명령:

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

## 데이터와 설정 수정

- 실시간 데이터 통합: `src/lib/api/fetch-live-observations.ts`
- 부산권 관측소 코드: `src/data/observation-stations.ts`
- 연결 실패용 예시 관측값: `src/data/marine-observations.ts`
- 부산 해역과 좌표: `src/data/sea-areas.ts`
- 어종 및 선호 환경: `src/data/fish-conditions.ts`

API 결과 또는 예시 데이터가 바뀌면 대시보드, 지도, 차트, 전체 어종 예측이 자동으로 다시 계산됩니다. 각 해역에는 가장 가까운 부산권 해양관측부이 값이 매칭되고, 기온·풍속·풍향·강수 상태는 각 해역 좌표를 기상청 격자로 변환해 조회합니다. 부산 해역을 추가할 때는 `sea-areas.ts`와 폴백용 `marine-observations.ts`에 같은 `areaId`를 추가합니다. 새 어종은 `fish-conditions.ts`에 조건 객체 하나를 추가하면 전체 순위에 포함됩니다.

## 점수 계산 방식

수온 50%, 계절 20%, 풍속 10%, 파고 10%, 조류 10%의 기본 가중치를 적용합니다. 각 항목을 0~100점으로 바꾼 뒤 가중 평균하며, 누락된 항목은 0점 처리하지 않고 제외한 다음 남은 가중치를 다시 정규화합니다. 결과는 항상 0~100 범위입니다.

- 80~100: 매우 높음
- 60~79: 높음
- 40~59: 보통
- 20~39: 낮음
- 0~19: 매우 낮음

이 점수는 **실제 포획 확률이 아니라 규칙 기반 환경 적합도 환산값**입니다. 출현·어획에는 먹이, 염분, 수심, 어군 이동, 조업 장비와 방식, 국지 기상 등 앱이 반영하지 않은 변수가 많습니다.

## 현재 한계와 발전 방향

현재는 가장 가까운 관측부이의 단일 시점 값을 해역 중심에 대표값으로 적용하며, 관리자가 설정한 선호 범위를 사용합니다. 관측소가 직접 제공하지 않는 항목은 누락될 수 있고, 국지적 차이를 완전히 반영하지 못합니다. 향후 시계열 수온, 염분, 용존산소, 수심별 조류 및 위치·시각별 실제 어획 기록을 확보하면 공간 보간, 데이터 품질 검증, 백테스트, 어종별 통계·머신러닝 모델과 예측 구간을 단계적으로 추가할 수 있습니다.
